# Jupyter Notebook

This folder contains the Jupyter Notebook used to implement the complete Week 2 logistics data preprocessing workflow.

## Notebook

`Week_2_Logistics_Preprocessing.ipynb`

## Purpose

The notebook provides a reproducible Python implementation of the data collection, cleaning, preprocessing, and analysis process.

## Main Steps

The notebook covers:

1. Importing Python libraries
2. Loading the raw logistics dataset
3. Exploring the dataset
4. Checking dataset dimensions
5. Examining column names and data types
6. Generating descriptive statistics
7. Checking missing values
8. Checking duplicate records
9. Validating numerical and categorical data
10. Converting the timestamp column to datetime format
11. Detecting potential outliers using the IQR method
12. Investigating potential outliers
13. Performing data cleaning
14. Applying Min-Max normalization
15. Analyzing numerical distributions
16. Performing correlation analysis
17. Creating visualizations
18. Performing final data-quality verification
19. Exporting the processed datasets

## Libraries Used

- Pandas
- NumPy
- Matplotlib
- Seaborn

## Outputs

The notebook generates:

- Cleaned logistics dataset
- Normalized logistics dataset
- Data-quality statistics
- Outlier analysis
- Distribution plots
- Correlation heatmap
- Other preprocessing visualizations

The notebook provides the complete reproducible implementation of the preprocessing pipeline.
