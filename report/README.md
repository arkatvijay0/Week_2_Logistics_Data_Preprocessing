# Project Report

This folder contains the detailed documentation for the Week 2 logistics data collection, cleaning, and preprocessing project.

## Report

`Week_2_Logistics_Data_Preprocessing_Report.docx`

## Report Overview

The report documents the complete methodology used to prepare the logistics dataset for further analysis.

## Contents

The report includes:

- Project objective
- Dataset selection
- Data collection simulation
- Dataset characteristics
- Data-quality assessment
- Missing-value analysis
- Duplicate analysis
- Data-type validation
- Timestamp preprocessing
- Outlier detection using the IQR method
- Outlier treatment methodology
- Min-Max normalization
- Distribution analysis
- Correlation analysis
- Python code snippets
- Data visualizations
- Results
- Impact of data quality on logistics analytics
- Reflection
- Conclusion
- References

## Purpose

The report connects the theoretical concepts of data preprocessing with their practical implementation in Python.

It explains why each preprocessing technique was selected and how data quality can influence logistics analytics and operational decision-making.
